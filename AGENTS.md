# Правила для агентов

1. Перед любыми изменениями сначала проверь состояние worktree и обнови текущую ветку из upstream через `git pull --ff-only`. Если worktree уже содержит изменения или fast-forward невозможен, не перетирай их и сообщи пользователю о блокере.
2. После любого изменения документации в этом репозитории или соседнем `../nanopi` завершай работу commit и push в соответствующий репозиторий. Не оставляй документационные изменения только локально.
